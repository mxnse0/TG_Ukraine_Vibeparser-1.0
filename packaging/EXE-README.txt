VibeParser.exe — приватний Telegram-бот для моніторингу фриланс-замовлень
=====================================================================

ЯК ЗАПУСТИТИ
-----------
1. Запусти VibeParser.exe подвійним кліком.
2. При першому запуску поруч з'явиться файл .env (шаблон налаштувань).
3. Відкрий .env у Notepad (бот сам запропонує це зробити) і встав
   справжній токен від @BotFather у рядок:

       BOT_TOKEN=123456789:AA...

4. Запусти VibeParser.exe ще раз.
5. Відкрий свого бота в Telegram і натисни /start.
   Перший цикл збереже старі замовлення без сповіщень — далі приходитимуть
   лише нові.

ДЕ ЩО ЛЕЖИТЬ
------------
  .env                  — налаштування (токен, фільтри, курси валют)
  data\vibeparser.db    — база замовлень, резюме та шаблонів
  data\resumes\         — завантажені файли резюме
  data\vibeparser.log   — лог роботи (якщо щось не працює)

КОРИСНІ КОМАНДИ (у PowerShell у цій теці)
-----------------------------------------
  .\VibeParser.exe demo
      згенерувати тестову картку замовлення

  .\VibeParser.exe status
      показати статистику бази

  .\VibeParser.exe sources --source freelancehunt --pages 1
      перевірити одне джерело без Telegram

ПРИМІТКИ
--------
* Другий запуск exe не створить конфлікт: бот повідомить, що вже працює.
* SCREENSHOT_MODE=page у exe не підтримується (Playwright не входить у
  збірку). Використовуй SCREENSHOT_MODE=card — це швидше й надійніше.
* Auto-bid для Freelancehunt потребує FREELANCEHUNT_TOKEN у .env.
* Якщо антивірус підозрює exe — це нормально для PyInstaller; додай файл
  у винятки або збери самостійно через build_exe.ps1.
